# Workflow

Interview OS is built incrementally.

## Milestone Process

1. Provide an implementation plan.
2. List files to create and modify.
3. List schema changes.
4. List routes.
5. List frontend pages.
6. List tests.
7. Wait for approval.
8. Implement only the approved milestone.
9. Update `docs/FEATURE_TRACKER.md`.
10. Update `docs/DECISIONS.md`.
11. Summarize completed work, known issues, and the recommended next milestone.
12. Stop.

## Guardrails

- Do not implement future milestones early.
- Do not add integrations unless explicitly approved.
- Do not add abstractions before the current milestone requires them.
- Keep the code simple, readable, and portfolio-quality.
